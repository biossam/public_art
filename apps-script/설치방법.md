# 작품 갤러리 설치 방법 (선생님용, 한 번만)

학생 작품은 **선생님의 구글 드라이브와 시트**에 저장됩니다. 학교 계정 대신 개인 구글 계정 사용을 권합니다.

1. 구글 드라이브에서 **새 구글 시트**를 만들고 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
2. (script.google.com에서 따로 만든 프로젝트여도 됩니다. 이 경우 처음 실행할 때 드라이브에 `예술가 퀘스트 작품` 시트가 자동으로 만들어집니다.)
3. 원래 있던 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙️)에서 **웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고, 권한 확인 창이 나오면 **허용**합니다. ("확인되지 않은 앱" 경고가 나오면 고급 → 이동)
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 Claude에게 알려 주거나, `index.html`의 `GALLERY_URL` 따옴표 안에 붙여 넣습니다.

## 코드를 고친 뒤 다시 배포하기 (주소 유지)

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. 이렇게 하면 웹 앱 주소가 바뀌지 않습니다.

## 작품 공개·숨기기

- 시트의 `작품` 탭에 학생이 올린 작품이 한 줄씩 쌓입니다.
- **공개** 칸을 체크하면 갤러리에 보이고, 체크를 풀면 바로 숨겨집니다.
- 올린 작품은 **바로 갤러리에 보입니다**(`APPROVAL_REQUIRED = false`). 욕설이 들어간 글은 저장되지 않습니다.
- 숨기고 싶은 작품은 시트의 `공개` 체크를 풀면 바로 사라집니다.
- 학생 갤러리에는 미술가별로 **베스트 5개**만 보입니다. 선생님 화면 '우리 반 작품 모아 보기'에서 ⭐를 눌러 고르고 **베스트 저장하기**를 누르면(또는 시트 `베스트` 칸에 직접 체크) 그 작품이 보이고, 체크한 작품이 없으면 최근 작품 5개가 보입니다.
- 선생님 확인 뒤에만 보이게 하려면 `APPROVAL_REQUIRED = true`로 바꾸고 새 버전으로 다시 배포하세요.
- 시트의 `사진 미리보기` 칸에서 올라온 사진을 바로 볼 수 있습니다.
- 사진 원본은 드라이브의 `예술가 퀘스트 작품 사진` 폴더 안 미술가별 폴더(`1편 공공미술가` ~ `4편 재사용 공공미술가`)에 저장됩니다. 예전에 올라온 사진은 편집기에서 `사진을_미술가별_폴더로_정리` 함수를 한 번 실행하면 옮겨집니다. 작품을 지우려면 시트 줄과 사진을 함께 지우세요.

## 주의

- 학생에게 **얼굴이 나오지 않게 작품만** 찍도록, **예술가 이름은 별명**으로 쓰도록 안내해 주세요.
